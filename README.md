# Big Mo's Luffas

A responsive, accessible static website for Big Mo's Luffas, designed for Azure Static Web Apps.

## Local preview

Open `index.html` directly or run:

```powershell
python -m http.server 8080
```

Then visit `http://localhost:8080`.

## Azure Static Web Apps

Use these build settings when connecting the GitHub repository:

| Setting | Value |
| --- | --- |
| App location | `/` |
| API location | *(blank)* |
| Output location | *(blank)* |

The site has no build step or runtime dependencies.
